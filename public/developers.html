SELFHOLD / FOR DEVELOPERS

Add Selfhold
to your site.

People connect their Selfhold account, approve writes to a Lattice chain and sign messages. Your site never holds a key, and every write is approved by the person.

One wallet object covers both ways people use Selfhold:

  • Selfhold for Chrome, where it is installed.
  • Selfhold's window everywhere else, phones included. wallet.selfhold.app opens over your page, as a payment window does. The account is a passkey, so there is nothing to install.

Quickstart

Load the script from Selfhold's own host. There is no build step:

<script type="module">
  import { selfhold } from "https://wallet.selfhold.app/v1/selfhold.js";

  const wallet = selfhold();

  // From a click: the browser opens Selfhold's window only in answer to one.
  connectButton.onclick = async () => {
    const address = await wallet.connect();
    show(`Connected as ${address}`);
  };

  saveButton.onclick = async () => {
    const sent = await wallet.writeRecords({
      chainPath: ["Nexus", "moniker"],
      actions: [{ key: "profile/bio", newValue: "Hello" }],
    });
    if (!sent) return; // nothing to send
    await sent.wait({ onChange: (state) => show(words[state]) });
    show("Saved.");
  };

  const words = {
    sent: "Sent. Your device's part is done. The network usually records it in about 10 seconds.",
    slow: "Taking longer than usual. It's sent and should still go through.",
    late: "The network hasn't recorded it yet. It may still go through.",
  };
</script>

The script is small and readable, so you can see what it runs. You can also copy it into your site and serve it yourself.

Call it from a click

connect, writeRecords and signMessage open a window, and browsers open windows only in direct answer to a click. Call them first in your click handler, before you await anything else.

If the write needs reading first, pass a promise. The window opens at once and waits for it. Resolving it to null closes the window and sends nothing.

button.onclick = () => wallet.writeRecords(readState().then(buildWrite));

After it's sent

A block comes every 10 seconds, so a write usually lands within seconds of being sent. sent.wait() tells you where it is, so you don't have to build that yourself:

StateWhenSay
sentat onceThe device's part is done. It usually lands in about 10 seconds.
slowafter 30 secondsIt's taking longer than usual, and should still go through.
lateafter 5 minutesIt hasn't landed yet. Offer a "Check again" button: sent.checkNow().
landedwait() resolvesDone. Draw the page from what the chain holds.

By default a write has landed once the account's nonce passes it. To decide from your own state instead, pass check: async () => true | false | "why". Return a string when another write landed in its place: after three reads that agree, wait() rejects with Lost and that string. After 30 minutes it rejects with NotRecorded.

API

selfhold(options?)

OptionDefault
use"auto"Selfhold for Chrome where installed, else the window. Or "window" or "extension" only.
hoststhe hosts Nexus lists() => string[]: the hosts a write is sent to and read from.
sponsornone() => string: a fee sponsor's URL. With one, Selfhold's window pays network fees with a few seconds of work on the person's device, so they need no coins.
walletwallet.selfhold.appThe window's page. Tests point it at a local copy.
wallet.kind
"extension" or "window": which one is in use right now.
wallet.connect() → address
Asks the person to connect. Call it from a click.
wallet.address() → address or null
The address this site was given. It never asks.
wallet.disconnect()
Forgets the address here.
wallet.writeRecords(request, { account?, progress? }) → Sent or null
Writes records on one chain, and pays addresses in the same transaction, once the person approves. request is { chainPath, actions: [{ key, oldValue?, newValue? }], payments?: [{ to, amount }], fee? }, or a promise of one. Pass account, the address you built the write for: if the wallet uses another now, nothing is sent. progress(text) hears what the window is doing.
wallet.signMessage({ text }) → { publicKey, signature }
Signs "lattice-message:" + your origin + "\n" + text, once the person approves.

Errors

Every failure is a SelfholdError with a code, and a message you can show the person as it is.

codeWhat happened
PopupBlockedThe browser blocked the window: the call wasn't made from a click, or pop-ups are off for your site.
ClosedThe person closed the window. Nothing was signed.
DeclinedThe person declined.
ReloadedThe window was reloaded mid-call. Nothing was signed.
AccountChangedThe wallet uses another account now. Connect again.
NotConnectedNo account was given to this site. Connect first.
NeedsCoinsThe account can't pay. The error carries address, needed and balance, so you can ask for coins.
NoWalletuse: "extension", and Selfhold for Chrome isn't installed.
LostSent, but another write landed in its place.
NotRecordedSent, and still not recorded after 30 minutes.
FailedAnything else. The message says what.

Before you ship

  • Serve your page over https.
  • Don't send Cross-Origin-Opener-Policy: same-origin: it cuts your page off from the window. same-origin-allow-popups is fine.
  • On iPhone, Selfhold's window opens as a tab, and people come back to yours when it's done.
  • Selfhold for Chrome and Selfhold's window each keep their own account. Say which one your page is using.
